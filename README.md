# Grade Entry

O **Grade Entry** é um sistema desenvolvido como projeto acadêmico com o objetivo de auxiliar no **controle, registro e entrada de notas fiscais CDL**, buscando tornar o processo mais organizado, ágil e seguro.

Para o desenvolvimento do projeto, a empresa escolhida como organização parceira foi a **Alares**, unidade de **Poços de Caldas – MG**. A partir da análise das necessidades e dos processos envolvidos na empresa, o sistema foi planejado para contribuir com a organização das informações relacionadas às notas fiscais e facilitar o acompanhamento de seus registros.

O projeto busca aplicar, na prática, conhecimentos adquiridos ao longo do curso de **Análise e Desenvolvimento de Sistemas**, envolvendo levantamento de requisitos, modelagem de dados, desenvolvimento de software, interface de usuário e organização das informações.

### Objetivo

O principal objetivo do Grade Entry é oferecer uma solução para **centralizar e controlar a entrada de notas fiscais CDL**, reduzindo a dependência de processos manuais e proporcionando maior organização e facilidade no gerenciamento dessas informações.

### Empresa escolhida

**Alares — Poços de Caldas/MG**

A empresa foi escolhida como cenário de aplicação do projeto, permitindo que a equipe desenvolvesse uma solução baseada em uma necessidade real e em um contexto empresarial.

### Tecnologias e conceitos

Durante o desenvolvimento, serão aplicados conceitos de:

* Levantamento e análise de requisitos;
* Modelagem de banco de dados;
* Programação;
* Desenvolvimento de interfaces;
* Controle e armazenamento de informações;
* Validação de dados;
* Organização e documentação de sistemas.

O **Grade Entry** representa a aplicação prática dos conhecimentos adquiridos durante a graduação, buscando transformar uma necessidade identificada em uma solução tecnológica funcional.
